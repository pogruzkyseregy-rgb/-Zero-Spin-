# Zero Spin

Мессенджер для небольшого круга. Android, Kotlin, Jetpack Compose.

## Структура

- `app/src/main/java/com/zerospin/app/ui/ZeroSpinApp.kt` — каркас: шапка, нижняя панель, переключение экранов
- `ui/screens/` — Лента, Чаты, Галерея, Профиль, Настройки
- `ui/theme/` — цвета и тема
- `data/SampleData.kt` — тестовые посты и чаты (пока без сервера)
- `.github/workflows/build-apk.yml` — сборка APK в GitHub Actions

## Сборка через GitHub

1. Создайте на GitHub пустой репозиторий, например `zero-spin-android`.
2. Загрузите в него все файлы этой папки и отправьте в ветку `main`.
3. Откройте вкладку **Actions** в репозитории. Запустится workflow **Build APK**.
4. Когда сборка завершится (обычно 3–6 минут), откройте запуск и внизу в разделе **Artifacts** скачайте `zero-spin-debug-apk`.
5. Внутри архива лежит `app-debug.apk`. Перенесите его на телефон и установите. Android попросит разрешить установку из неизвестных источников: разрешите для вашего файлового менеджера или браузера.

Запустить сборку вручную можно кнопкой **Run workflow** на вкладке Actions.

## Локальная сборка (необязательно)

Нужны JDK 17, Android SDK и Gradle 8.9+:

```
gradle :app:assembleDebug
```

APK появится в `app/build/outputs/apk/debug/`.
