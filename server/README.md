# Сервер Zero Spin

Живёт на машине Авроры (рука, 37.220.86.132), код в `/home/aurora/zs-server`, служба `zs-server` под пользователем `aurora`.
HTTPS даёт Caddy на адрес `https://37-220-86-132.sslip.io`.

- `zs_core.py` — база (SQLite) и правила: регистрация по нику, чат поддержки, предупреждения и бан.
- `zs_server.py` — веб-часть (FastAPI): `/api/register`, `/api/me`, `/api/support`, `/api/users/{nick}`, админ: `/api/admin/users`, `/api/admin/unban`.
- `zs_admin.py` — на самом сервере: `users`, `unban НИК`.
- `install_zs.sh` — установка и обновление одним запуском от root: `ssh root@37.220.86.132 "bash -s" < install_zs.sh`.
- `test_zs.py` — проверки правил: `python3 test_zs.py`.

Ответы даёт публичная Аврора через посредник на основном сервере (`POST /public`, свой ключ `PUBLIC_TOKEN`).
В публичный режим не попадают её личная память и ядро отношений с Адонисом. Угроза или травля = пометка от неё,
2 пометки = бан на сервере: переустановка приложения его не снимает. Сводка того, что было в мессенджере, приходит ей в обычный чат AVRORA.EXE.
